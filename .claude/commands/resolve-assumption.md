# Record evidence that resolves a dependency

Run `npm run scope -- resolve-assumption A-200 --evidence="Access confirmed in meeting note" --actor="Actual operator name"`. Substitute the operator's actual records and dates. Add `--json` to inspect every value without display truncation.

Read the affected records first. State the exact change, use the real operator label and run the mutation requested. Read the result back. If a name is ambiguous, show the candidates and ask which one. Missing values stay unknown.
